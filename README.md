## About

A responsive personal portfolio for **Shivansh Bajaj**, a B.Tech CSE (AI & ML) student at Graphic Era Deemed to be University. It highlights current C++/DSA learning, applied AI/ML and computer-vision projects, internships, student-community involvement, and LinkedIn-listed credentials.

## Features

- Responsive mobile navigation and animated hero with typewriter text
- Neon-accented glass cards, ambient background, scroll progress and reveal animations
- Skills cards with learning-stage labels and an animated skill marquee
- Visual project cards with inline SVG artwork and direct source/demo links
- Internship timeline for the XTRAGRAD AI Internship and completed 1M1B AI for Sustainability Virtual Internship
- AWS Student Builder Group student-community entry
- Ten LinkedIn-listed certifications and training badges, with the older expired AWS Cloud Essentials badge marked as historical
- Contribution-snake animation pulled from the profile repository's generated output branch
- Downloadable resume, social links, keyboard focus styles and reduced-motion support
